# Syncfusion Scheduler Demo

This minimal demo shows the Syncfusion React Scheduler running inside a Vite-powered React app.

Quick start (Windows PowerShell):

```powershell
npm install
npm run dev
```

Open the local server URL shown by Vite in your browser (usually http://localhost:5173).

Notes:
- The project uses the already-downloaded Syncfusion package referenced in `package.json`.
- If you have a Syncfusion license, follow Syncfusion's instructions to register it.
